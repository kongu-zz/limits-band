# limits-band

Мод для [Claude Code](https://code.claude.com/docs/en/): полоса над строкой ввода с лимитами подписки, контекстом, моделью, effort и стоимостью сессии.

*A Claude Code mod that shows plan limits, context, model, effort and session cost above the prompt. Labels are in Russian and times are in Europe/Madrid.*

```
Opus 5.5 │ контекст 22% │ my-project (main*) │ ● high │ сессия ≈$3.76
неделя ●●●●●●○○○○  60% ⟳ 9 ноя 05:00 (Мадрид) / 04:00Z
обновлено 20:15 (Мадрид) / 19:15Z
```

## Зачем

Самодельные скрипты для строки состояния часто показывают устаревшие цифры: например, берут лимит из старого кэша, когда в данных сессии нет одного из окон. Этот мод получает цифры прямо от Claude Code и не показывает окно, срок которого уже прошёл.

## Что умеет

- **Лимиты:** шкала, процент и время сброса для каждого окна, которое сейчас есть. Цвет зелёный, с 70% жёлтый, с 90% красный.
- **Предупреждения:** уведомление на 80% и 90%, по одному разу на окно.
- **Сессия:** модель, заполнение контекста, папка, ветка git и effort реального запроса к модели. Запросы субагентов на effort не влияют.
- **Стоимость:** `сессия ≈$…` показывает оценку по ценам API. Это не счёт: при подписке расход ограничивают лимиты.
- **Команда `/limits`:** выводит те же цифры текстом и открывает панель, поэтому работает и там, где полосы нет.

До первого ответа модели в сессии данных о лимитах нет, а effort показан как `effort —`.

## Установка

В сессии Claude Code в терминале:

```
/plugin install limits-band --marketplace kongu-zz/limits-band
```

Ответьте `y` на вопрос о добавлении marketplace и выберите область установки.

Из командной строки:

```
claude plugin install limits-band --marketplace kongu-zz/limits-band
```

В приложении для компьютера, где `/plugin` не работает: нажмите **+** рядом с полем ввода, затем **Plugins**, **Add marketplace** с адресом `kongu-zz/limits-band`, затем **Add plugin**.

Обновление:

```
claude plugin update limits-band
```

## Где что видно

| Где | Полоса над вводом | `/limits` | Проверено |
|---|---|---|---|
| Терминал | Да | Да | На экране |
| Телефон через Remote Control | Нет | Да, текстом | На экране |
| Приложение для компьютера | Да | Да | По описанию API и тестам |
| VS Code | Нет | Да | По описанию API и тестам |

Работа в облачных сессиях не проверялась.

## Ограничения

- Подписи только на русском, время только по Мадриду и UTC.
- Расход других сессий виден после следующего ответа модели в этой сессии.
- Claude Code не передаёт модам недельный лимит отдельной модели. Его можно посмотреть в `/usage`.
- API модов находится в раннем доступе и может измениться между версиями Claude Code. Мод проверен на версии 2.1.319.

## Разработка

Запуск из папки с исходниками:

```
claude --plugin-dir <путь к папке мода>
```

Проверки:

```
claude plugin validate .
claude plugin test .
npx -p typescript@5.6.3 tsc -p .
```

Файл `tsconfig.json` опирается на типы, которые Claude Code создаёт в `.claude-plugin/types/` при загрузке мода, поэтому проверку типов запускайте после первой загрузки.

| Файл | Что в нём |
|---|---|
| `hooks/register.tsx` | События и отрисовка |
| `hooks/format.ts` | Шкала, время, пороги, подписи |
| `types/index.d.ts` | Значения, которые хранит мод |
| `tests/limits.test.tsx` | Тесты |
